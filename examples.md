# Worked screens

Sample figures. Match the patterns, not these numbers.

## Ledger: Sandakan orders

Mode: ledger. Title is the site code SDK with Sandakan once beside it. The sentence states the open balance.

Filter row: Item groups or Sales groups, created from, created to, find, Apply. Apply hides non-matching lines already loaded. Find waits 300ms.

Result: GROC selected in the rail. The table heads are sticky. Amounts are right-aligned and tabular. A late ship date is red and weight 600, with the date written out. The footing is line count, total, and balance.

Sign out sits under the branch codes. v1.0 at the bottom right opens the notes dialog.

## Process: CP shipment upload

Mode: process. Title is Upload. The sentence says to pick a principal and a workbook.

An amber banner is present only on a development site.

Named choices, one selected: 140 | 141 RB, 168 CP, 181 MMS, 111 UNZA, 160 KAO. The selected card has a blue left edge.

The drop zone is a labelled file input. After a file is chosen, its name shows and Process & Download enables and submits the form. Cancel clears the file and disables Process again.

The warehouse table for the selected principal has a filter row under the heads: kind, map key, site, warehouse. Filtering hides rows in the table. It does not reload the page.

The version at the bottom right opens the notes dialog.
